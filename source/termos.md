###  **Inteligência Artificial e Machine Learning:**

| Termo | Explicação Breve |
|-------|-----------------|
| **Machine Learning (ML)** | Técnicas que permitem computadores aprenderem padrões a partir de dados sem serem explicitamente programados. |
| **Deep Learning (DNN)** | Tipo de ML que usa redes neurais com muitas camadas para aprender representações complexas. |
| **MLP (Multilayer Perceptron)** | Rede neural artificial com múltiplas camadas de neurônios, usada para regressão/classificação. |
| **ReLU** | Função de ativação que retorna zero para valores negativos e o próprio valor para positivos. |
| **Dropout** | Técnica de regularização que "desliga" neurônios aleatoriamente durante treino para evitar overfitting. |
| **Otimizador Adam** | Algoritmo que ajusta os pesos da rede neural de forma eficiente durante o treino. |
| **MSE (Mean Squared Error)** | Métrica que mede o erro médio quadrático entre previsões e valores reais. |
| **Ensemble e Boosting** | Técnicas que combinam múltiplos modelos para melhorar a precisão (ex: Gradient Boosting). |
| **GradientBoostingRegressor** | Modelo que combina várias árvores de decisão fracas em uma forte, passo a passo. |
| **XGBRegressor (XGBoost)** | Implementação otimizada e rápida do gradient boosting, muito usada em competições. |
| **LightGBM** | Outro framework de gradient boosting, mais rápido e com menor uso de memória. |
| **Validação cruzada (k-fold)** | Técnica para avaliar modelos dividindo os dados em k partes, treinando e testando em rodadas alternadas. |
| **Data leakage** | Erro que ocorre quando informações do conjunto de teste "vazam" para o treino, inflando resultados. |
| **Pipeline** | Sequência automatizada de etapas (pré-processamento, modelagem) para evitar vazamento. |
| **StandardScaler (Z-score)** | Normalização que transforma dados para média 0 e desvio padrão 1. |

###  **Avaliação e Métricas:**

| Termo | Explicação Breve |
|-------|-----------------|
| **R²** | Mede quanto da variação dos dados é explicada pelo modelo (0 a 1, quanto maior melhor). |
| **RMSE** | Raiz do erro quadrático médio — penaliza erros grandes mais severamente. |
| **MAE** | Erro absoluto médio — mais fácil de interpretar, não penaliza tanto outliers. |
| **APE** | Erro percentual absoluto — erro em porcentagem, útil para comparar escalas diferentes. |
| **Out-of-fold (OOF)** | Previsões feitas em dados não usados no treino durante validação cruzada. |
| **Overfitting** | Quando o modelo se ajusta demais aos dados de treino e perde capacidade de generalizar. |
| **Generalização** | Capacidade do modelo de performar bem em dados novos e não vistos. |

###  **Interpretabilidade e XAI:**

| Termo | Explicação Breve |
|-------|-----------------|
| **XAI** | Conjunto de técnicas para explicar decisões de modelos complexos (como redes neurais). |
| **SHAP** | Método baseado na Teoria dos Jogos para explicar a contribuição de cada variável na previsão. |
| **TreeExplainer** | Versão do SHAP otimizada para modelos baseados em árvores (como XGBoost). |
| **Feature importance** | Medida de quanto cada variável contribui para as previsões do modelo. |

---

### **Processamento de Dados e Estatística:**

| Termo | Explicação Breve |
|-------|-----------------|
| **Regressão Linear Múltipla (MLR)** | Modelo estatístico que relaciona várias variáveis independentes a uma dependente. |
| **Mínimos Quadrados Ordinários (OLS)** | Método para estimar os coeficientes da regressão minimizando a soma dos erros quadrados. |
| **Matriz de correlação de Pearson** | Tabela que mostra a correlação linear entre pares de variáveis (-1 a 1). |
| **Multicolinearidade** | Quando variáveis independentes estão altamente correlacionadas, prejudicando a regressão. |
| **Feature engineering** | Processo de criar, selecionar ou transformar variáveis para melhorar o modelo. |
| **Pré-processamento** | Preparação dos dados antes do treino (normalização, limpeza, etc.). |
| **Benchmarking automatizado** | Uso de ferramentas para testar vários modelos rapidamente (ex: LazyPredict). |

###  **Termos de Fenomenologia e Engenharia:**

| Termo | Explicação Breve |
|-------|-----------------|
| **Resistência residual à flexão (fR,1, fR,3)** | Resistência do concreto após fissuração, em diferentes aberturas de fissura. |
| **CMOD** | Abertura de fissura medida no ensaio de flexão. |
| **Pull-out** | Mecanismo de arrancamento das fibras da matriz de concreto. |
| **Crack bridging** | Capacidade das fibras de transferir tensões através de uma fissura. |
